# 牛個体情報検索（耳標OCR対応）

## 機能
- 耳標番号の手入力検索（10桁、または大きい4桁・下5桁・先頭9桁でも検索可）
- iPhoneカメラで耳標に印字された**数字をそのまま読み取って**検索（OCR）

## 読み取りのしくみ
- 読み取りエンジンは `interbcd/`（耳標リーダー）から移植し、`ocr-scanner.js` にまとめています
- 黄色いタグを探して、印字の数字を Tesseract.js で読み取ります（バーコードは使いません）
- 距離によって読める桁数が変わります：大きい4桁 → +CD（5桁）→ 上段5桁つき（9桁/10桁）
- 読めた桁で `master.csv` と照合し、候補を表示します
  - 本確定（3回一致）で1頭に絞れたら、自動で検索結果を表示
  - 候補が複数あるときは一覧から選択
  - 読み取った数字をタップすると、そのまま入力欄に入れます
- 詳しい設計・調整ポイントは `interbcd/DESIGN.md` を参照

## 使い方
1. GitHub Pages で公開
2. Safari(iPhone)でアクセス
3. カメラボタン → 耳標の数字にかざす

## 注意
- HTTPS必須（GitHub Pages OK）
- Safari推奨
- OCRエンジン（Tesseract.js）はCDNから読み込むため、初回は数秒〜十数秒かかります（ネット接続が必要）
